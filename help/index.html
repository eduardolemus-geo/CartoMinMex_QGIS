CartoMinMex_QGIS

Carga la capa oficial de concesiones mineras (SE/DGM) y detecta cortes/actualizaciones.

Instalación

  1. Descarga el ZIP de la Release y en QGIS: Complementos → Administrar… → Instalar desde ZIP.

Uso

  1. Web → CartoMinMex_QGIS → abre el panel.
  2. “Cargar CartoMinMex” añade la capa al proyecto.
  3. “Comprobar/Actualizar” revisa servicio/corte más reciente.

Fuente de datos

Catálogo ArcGIS REST de SE: .../rest/services. El plugin busca Concesiones_Mineras_Vigentes_YYYY y usa la capa 0.

FAQ

Requiere QGIS 3.x y acceso a Internet. Respeta proxy/autenticación de QGIS.
